About me

Hi, I’m Ethan.

I’m a Year 2 Information Technology student at Singapore Polytechnic, minoring in Business. I got into programming through robotics. It earned me a Direct School Admission place at Maris Stella High School, where I went on to mentor juniors in the Robotics & Programming Club and win a Merit Award at an international coding competition.

Now I like owning a project end to end: designing the database, writing the API, making the interface clear and getting it live where people can use it. I also go back to my older school projects and rebuild them properly, fixing the security gaps, hard-coded values and accessibility issues I didn’t know about in Year 1.

Away from the keyboard, I’ve worked part-time on busy kitchen lines, emceed school events and volunteered at community events with 100+ participants.

I revisit my Year 1 projects with what I know now and fix what I missed the first time.

  • PokémonAny logged-in player could act on another player’s account, and gym rewards could be claimed more than once.Ownership checks on every player route, rewards only for a won battle, and every purchase run as one database transaction.
  • Retail AppA hard-coded server address and payment list, plus data-loading bugs on the server.100,000 rows packed into compact JSON, so it runs on GitHub Pages with no server at all.
  • Wellness HubConsole errors, unescaped user input and broken mobile layouts.Escaped input, labelled controls, live regions, reduced motion and keyboard focus.

Tests run in GitHub Actions on every push to main. In RAG Search and Trend Tracker, a failing test blocks the deploy, so a broken change never reaches the live demo.
