# Ethan Yap · Portfolio

Personal portfolio of Ethan Yap, Year 2 Information Technology student at Singapore Polytechnic, seeking a software engineering internship.

**Live site:** https://ethanyap123.github.io/portfolio/

It covers my projects (live demos, source code, case studies and what each one taught me), skills, how I work, education, experience and a downloadable [resume](assets/Ethan-Yap-Resume.pdf).

## Built with

Plain HTML and CSS with a little vanilla JavaScript, no framework and no build step. `index.html` is the home page, where projects and skills are rendered from small data arrays. Each in-depth project has a case study page in `work/` with an architecture diagram (`assets/diagrams/`), sharing `assets/case-study.css`.

GitHub Actions validates every page and checks every local link on each pull request, and GitHub Pages serves the site from `main`.

Run it locally with any static server, for example:

```bash
python -m http.server 8174
```
